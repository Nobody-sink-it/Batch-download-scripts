# 一个简单的批量下载辅助脚本

## 前言
作为一只赛博仓鼠，在浏览网页的时候常常会遇到一些精妙绝伦的文章或者非常精彩的视频，此时的我就非常想要把它们收藏起来，以便于以后的我慢慢欣赏或者反复地观看

然而事情有时候并没有那么的好，第一，出于各种原因，很多资源并不是一成不变的，可能来自于平台的封禁，版权方的举报，或者是创作者个人的原因，无法再进行免费的分享，许多优秀的东西就这样消失在互联网上了；第二，各个平台的相互独立性，在平台内部收藏的东西并不能够互通，给我们分类整理造成了很多的困难

所以说，作为一个爱好收藏各种各样稀奇古怪玩意的人，希望有一个趁手的下载辅助工具的需求就十分迫切了，许多东西能够快速的存储在云上，并能够显著的减少本地占有的空间
## 做了什么？
这个项目是如何做出来的呢？首先说明的是，这个项目极其的简单，甚至很大一部分成功来自于vibe coding，但考虑到我只是个初学者非科班人士，只要东西做出来就好了嘛
## 有什么帮助？
1. 可以实现音频、视频、文字等大多数常见文件格式的存储
2. 操作简单易上手，极致的清凉级，所用到的函数均来自于python标准库，只需要安装较新的python版本
3. 云端存储，浏览器的下载文件会被剪切到经分类整理后的文件夹，所有资源均在云端有一处存储位置，用户可自行决定是否删除本地的文件
